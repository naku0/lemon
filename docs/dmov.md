# Прямой импорт DMOV

Для записей Лаб2 подтверждён профиль:

```text
u32 BE body length
'T'
u32 LE tick
fragmented A<digit><u8> fields
```

Поля могут пересекать границу бинарной записи. Декодер проверяет длину до выделения памяти, ограничивает размер записи, сохраняет порядок и отклоняет повреждённые или оборванные файлы с байтовым смещением.

В Лаб2 поток содержит `A0` и `A2`. Извлекаются только эти поля:

```bash
lemon import \
  "$HOME/Downloads/Лаб2/фон/5_10_2026_12_17_26.dmov" \
  --output recordings/lab2-background
```

Проверка по сопутствующим DAT установила: `A0 → *_EMG.dat`, `A2 → *_EEG.dat`. Это исторические имена экспорта, а не физиологическая классификация. Значения сохраняются без масштабирования как `adc_counts_u8`.

Пакетные ticks сохраняются в `DmovPacket` events. Они не доказывают одновременность измерений каналов, поэтому `synchronized_clock=false`; временная ось реконструируется по индексу и номинальной/оценённой частоте. Соответствие A0/A2 электродам C3/C4 задаёт пользователь.
